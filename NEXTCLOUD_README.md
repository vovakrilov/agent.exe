# Nextcloud Server Setup

Ваш Nextcloud сервер успешно настроен и запущен!

## 🚀 Доступ к серверу

- **Web-интерфейс**: http://localhost:8080
- **Состояние**: Все сервисы запущены и работают

## 📋 Первоначальная настройка

1. Откройте браузер и перейдите по адресу: http://localhost:8080
2. Создайте учетную запись администратора:
   - Введите желаемое имя пользователя
   - Введите надежный пароль
3. База данных уже настроена автоматически (MariaDB)
4. Нажмите "Завершить установку"

## 🛠️ Управление сервером

### Запуск сервера
```bash
./start-nextcloud.sh
```

### Проверка состояния
```bash
sudo docker compose ps
```

### Просмотр логов
```bash
sudo docker compose logs -f nextcloud-app
```

### Остановка сервера
```bash
sudo docker compose down
```

### Полная остановка с удалением данных
```bash
sudo docker compose down -v
```

## 📦 Компоненты

- **Nextcloud**: Версия 28 с Apache
- **База данных**: MariaDB 10.11
- **Кеш**: Redis 7
- **Порт**: 8080

## 🔧 Конфигурация

- Все данные сохраняются в Docker volumes
- База данных автоматически настроена
- Redis используется для кеширования и повышения производительности

## 📁 Файлы проекта

- `docker-compose.yml` - Конфигурация Docker Compose
- `start-nextcloud.sh` - Скрипт запуска
- `NEXTCLOUD_README.md` - Эта инструкция

## 🔐 Безопасность

- Измените пароли по умолчанию в production
- Рассмотрите возможность использования HTTPS
- Регулярно обновляйте Nextcloud и компоненты
